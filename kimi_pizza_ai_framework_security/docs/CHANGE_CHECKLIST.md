# Checklist de cambios

- [ ] Revisé implementación existente.
- [ ] Reutilicé lo que ya existe.
- [ ] No añadí duplicidad.
- [ ] Separé UI de lógica.
- [ ] Respeté la capa correcta.
- [ ] Revisé seguridad/permisos.
- [ ] Revisé persistencia.
- [ ] Revisé inventario si aplica.
- [ ] Revisé caja si aplica.
- [ ] Revisé reportes si aplica.
- [ ] Escribí/actualicé pruebas relevantes.
- [ ] Ejecuté pruebas.
- [ ] Revisé regresiones.
- [ ] Actualicé documentación si cambió una regla.
