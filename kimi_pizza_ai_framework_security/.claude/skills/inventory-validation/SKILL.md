# Skill: Inventory Validation

Antes de modificar inventario:

1. Leer `docs/INVENTORY.md`.
2. Leer `docs/PRODUCT_RECIPES_INVENTORY_PREPARATION.md`.
3. Identificar el tipo de movimiento.
4. Determinar si modifica insumo, preparación o ambos.
5. Comprobar unidad y conversión.
6. Comprobar disponibilidad.
7. Evitar doble descuento.
8. Registrar movimiento trazable.
9. Comprobar idempotencia.
10. Ejecutar regresión de compras → preparación → ventas → mermas.
