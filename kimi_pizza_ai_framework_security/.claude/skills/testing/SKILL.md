# Skill: Testing

## Antes

- Identificar reglas de negocio nuevas o modificadas.
- Revisar pruebas existentes.
- Definir el caso feliz y casos límite.

## Durante

Probar como mínimo la lógica de dominio afectada y sus integraciones directas.

## Después

1. Ejecutar pruebas unitarias.
2. Ejecutar widget tests afectados.
3. Ejecutar integration tests cuando corresponda.
4. Ejecutar regresión de módulos conectados.
5. Documentar cualquier prueba pendiente.

No considerar terminado un cambio crítico solo porque la app compila.
