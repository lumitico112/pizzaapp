# Skill: Flutter Refactoring

1. No cambiar comportamiento sano sin necesidad.
2. Identificar responsabilidades antes de separar clases.
3. Extraer lógica de UI hacia dominio/presentation según corresponda.
4. Consolidar duplicaciones.
5. Mantener APIs internas estables cuando sea posible.
6. Refactorizar acompañado de pruebas.
7. Evitar sobreingeniería.
8. Después del refactor revisar imports, dependencias, rutas y regresiones.
