# Skill: Flutter Debugging

## Flujo obligatorio

1. Leer `AGENTS.md`.
2. Leer la documentación del dominio afectado.
3. Reproducir o reconstruir el flujo.
4. Identificar la causa raíz, no solo el síntoma.
5. Buscar el origen de los datos.
6. Trazar eventos entre módulos.
7. Revisar estado, persistencia y concurrencia.
8. Implementar la corrección en la capa correcta.
9. Ejecutar la prueba que demuestra la corrección.
10. Ejecutar pruebas de regresión.
11. Buscar duplicidad o deuda técnica introducida por el cambio.

## Prohibido

- Parches arbitrarios en UI.
- Duplicar un servicio existente.
- Cambiar stock directamente desde una pantalla.
- Ocultar un error solo para que la UI parezca correcta.
- Declarar resuelto el bug sin prueba.
